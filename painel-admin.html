Entre com sua conta do Firebase Authentication para acessar o painel privado.
Como ativar no Console do Firebase (1x)

1. No Firebase Console, vá em Authentication → Sign-in method e ative E-mail/senha.

2. Em Authentication → Users, crie seu usuário (e-mail e senha).

3. Em Configurações do projeto → Geral, copie a Chave da API da Web (Web API Key).

4. Em Realtime Database → Regras, cole:
